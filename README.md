# Java Básico — IO_JDBC_Concorrencia_Testes_Build_Logging_Spring_Boot

Exercícios 01 a 10 da apostila de Java da Faculdade Flamingo.

Neste projeto, pratiquei leitura e escrita de arquivos, threads, testes com JUnit, Maven e logs.

## Como executar

Abra o projeto no IntelliJ com Java 17 e rode o `main` da classe do exercício. Rode o exercício 01 antes dos exercícios 02 e 04, pois eles usam o arquivo criado por ele.

Para rodar o teste, use `mvn test` na pasta do projeto.
